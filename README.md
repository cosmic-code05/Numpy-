# NumPy Notes

## What is NumPy?
NumPy (Numerical Python) is a Python library used for fast numerical computing. It provides support for multi-dimensional arrays and mathematical operations on them.

## Why use NumPy?
Faster than Python lists

Consumes less memory

Supports vectorized operations

Widely used in Data Science, Machine Learning, and AI
